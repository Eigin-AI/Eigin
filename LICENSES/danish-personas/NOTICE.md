The unchanged dataset README is preserved in `dataset-card.md`.

Eigin retains five original synthetic source records in `.pi/panel/sources/`.
Narrative portraits in `.pi/panel/personas/` develop those source biographies for roleplaying.
Fictional display names, AI experience, everyday habits, and additional personal details
are authored by Eigin. The profile README identifies the grounding and additions.
These additions are not source statistics.

The dataset uses Statistics Denmark (Danmarks Statistik) aggregate material under
Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/
License text: `CC-BY-4.0.txt`.
Source tables and reference periods are listed with links in `dataset-card.md`,
including FOLK1A, FOLK2, RAS209, RAS202, LONS20, and NUTS_V1_2007_DK.
Source organization: https://www.dst.dk/ ; tables: https://www.statbank.dk/ .

The upstream pipeline samples and transforms aggregate statistics and adds synthetic
attributes and generated prose. Eigin selects records and adds the assumptions
listed above. Neither Statistics Denmark nor the dataset creator endorses Eigin
or these simulated reviews. These are fictional records, not individual respondents.
