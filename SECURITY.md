# Security Policy

## Reporting a vulnerability

Please use the [Security Disclosure issue template](https://code.eigin.ai/dev/eigin/-/issues/new?issuable_template=security_disclosure) to report a vulnerability. When filing the issue:

- Mark it as **confidential**
- Apply the `security` label

If you prefer not to use GitLab, email [security@eigin.ai](mailto:security@eigin.ai) instead.

## What to include

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Affected component and version (if known)

## Response

We aim to acknowledge reports within a week and remediate as soon as possible, keeping you informed throughout.

## Scope

We welcome reports for any Eigin component where there is a realistic security impact.

The following are out of scope:

- Social engineering
- Issues with no practical impact on users or data
- Vulnerabilities in third-party providers or dependencies that we cannot fix
- Theoretical attacks with no viable exploitation path

## Bug bounty

We do not currently run a bug bounty program.
