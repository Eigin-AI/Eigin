# Grant Signing Keys

**Credit grants** are credits issued directly by a trusted issuer (us, or an enterprise
admin) rather than through a store. A grant is an Ed25519-signed JWT, redeemed at
`POST /v1/credits/redeem` with `type: "grant"`. The relay verifies it against the public
key in `GRANT_PUBLIC_KEY`; the matching private key can mint credits and is kept secret.

Keys are managed differently for local dev and deployed environments.

## Local development

`just grant keygen` writes a throwaway keypair here (`grant_private.pem`,
`grant_public.pem`, both gitignored). `just run relay` loads `grant_public.pem` into
`GRANT_PUBLIC_KEY`, and `just grant sign` signs against the local private key. This key
is for local testing only and never goes anywhere.

```
# write the local dev keypair
just grant keygen

# sign a grant for default product
just grant sign

# sign a specific product
just grant sign eigin.credits.v1.grant.500
```

The product tier must exist in `config/products.toml` (`eigin.credits.v1.grant.<tier>`).

## Deployed environments

Each environment's keypair is generated by Terraform (`tls_private_key.grant` in
`infra/scaleway/modules/relay/secrets.tf`) and lives in that workspace's state, so
staging and production never share a key. The public key is wired into the container as
`GRANT_PUBLIC_KEY` automatically.

To sign a grant for a deployed environment, pull its private key from state:

```
just grant sign-remote staging                            # default product tier
just grant sign-remote staging eigin.credits.v1.grant.500
```

To rotate an environment's key, replace the resource:

```
terraform apply -replace=module.relay.tls_private_key.grant
```

Rotation invalidates grants that were issued but not yet redeemed; already-redeemed
wallets are unaffected.
