# Markdown rendering

This folder is Eigin's markdown renderer: the streaming parser, inline/block
conversion, and the `ParagraphUIView` streaming engine that draws paragraphs,
lists, block quotes and math.

It is derived from Microsoft's SwiftStreamingMarkdown, modified and re-themed
for Eigin. See
[`LICENSES/swift-streaming-markdown.md`](../../../../../../../LICENSES/swift-streaming-markdown.md)
for provenance, license and attribution.
