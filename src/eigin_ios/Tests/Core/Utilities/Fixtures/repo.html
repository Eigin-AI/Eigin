README

SoupKit is a pure library for parsing messy markup. It conforms to the WHATWG parsing specification and runs on macOS, iOS, tvOS, watchOS, and Linux.

Installation

dependencies: [
    .package(url: "https://code.example.com/scinfu/soupkit.git", from: "2.13.0"),
]

Clean HTML for security

Remove unsafe markup with a whitelist:

let clean = try SoupKit.clean(
    "<button onclick=bad()>Click</button><b>Important text</b>",
    whitelist: Whitelist.basic()
)
