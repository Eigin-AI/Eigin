fetch()

The fetch() method starts an HTTP request and returns a promise. Unlike XMLHttpRequest, it works with promises.

Calling fetch(resource, options) returns a Promise that resolves to a Response object once headers arrive.

Requesting JSON

A minimal request looks like this:

async function getData() {
  const response = await fetch("https://api.example.org/products.json");
  if (!response.ok) {
    throw new Error(`Status: ${response.status}`);
  }
  return response.json();
}
